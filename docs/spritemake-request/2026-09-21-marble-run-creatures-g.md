## 4. QA (기존 배치와 동일 + 종 구분)

1. row2 col0 공: alpha bbox 중심 (80,80) ±2px, 지름 108~120 — 3종 모두, 기존 5종과 같은 범위
2. row1 col3 == row2 col0 (diff 0)
3. 28px 축소 대조 시트에 **기존 5종 + 새 3종** 8마리 — 복어 vs 고슴도치, 너구리 vs 아르마딜로/공벌레가 구분되는지
4. 각 셀 alpha≥8 bbox 가 셀 경계를 넘지 않음, alpha 1~7 = 0, halo 0, md5 기록
5. sleep·scuffle 은 1차 시트와 같은 캐릭터인지(색·비율) 눈검사

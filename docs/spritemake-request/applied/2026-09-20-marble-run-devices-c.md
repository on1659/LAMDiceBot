## 1. 왜 3차인가

트랙 중반(풍차 아래)이 "긴 대각선 경사로"뿐이라 순위가 안 바뀌었다. 그 자리를 **타이밍·순서 운으로 순위가 뒤집히는 장치 4종**으로 바꿨다.
코드는 이미 들어가 있고(코드 도형으로 그려짐), 에셋이 오면 그림만 교체한다. 물리 크기가 정해져 있으니 아래 소스 크기를 지켜야 한다.

```text
⑦   두더지 경사로   경사로 2단(오른쪽↘, 왼쪽↙) 위 두더지 구멍 3개씩. 두더지가 제 박자로 튀어나오면
                    그 순간 머리 위에 있던 동물만 위로 튕겨 오른다 (항상 켜진 점프대가 아니라 타이밍 운)
⑦-b 플립플롭 갈림길 좁은 통로 아래 젖혀지는 팔. 동물이 지날 때마다 반대로 젖혀져
                    왼쪽 지름길 / 오른쪽 컨베이어 돌아가기를 번갈아 보낸다
     컨베이어 2단   돌아가는 길: 벨트가 오른쪽 끝까지 실어 나르고, 아래 벨트가 다시 왼쪽으로 — 약 2.5초 손해
     선풍기 2대     양쪽 벽에서 엇박으로 바람. 켜진 순간 띠 안에 있던 동물만 옆으로 밀린다
```

## 4. 코드 연결점 (에셋 도착 시)

`js/marble-render.js` `drawPieces` 안 `pieces.mole / pieces.flipflop / pieces.belt / pieces.fan` 블록 — 지금은 코드 도형. `ASSETS.pieces` 에 키를 추가하고 `drawSprite('pieces', …)` 가 false 를 돌려주면 코드 도형으로 남는 기존 패턴 그대로.
박자(period/up/phase)는 서버가 조각에 실어 보내고 클라 `deviceOn()` 이 같은 식으로 계산하므로, 프레임 선택은 `devicePhase()` 0~1 로 매핑하면 된다.

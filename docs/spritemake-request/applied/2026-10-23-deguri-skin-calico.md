# 데구리 삼색 고양이 스킨 2종 (2026-10-23)

사용자가 삼색 고양이 사진을 주며 "냥이 스킨 레어·에픽·레전더리로 3개, 하나 보고 고를 것" 요청.
삼색이 무늬로 등급별 시안 3장(배치 `deguri-skin-previews-cat-penguin-2026-10-23`, 서기 한 장씩)을 텔레그램 ⭕/❌ 버튼으로 보냈고,
사용자가 에픽·전설 두 개에 ⭕ → "둘 다 만들어". 사진은 입력하지 않고 무늬만 글로 설명했다.

| 시트 | 이름 | 등급 | 근거 | 시안 |
|---|---|---|---|---|
| cat-yarn | 털실 삼색냥 | epic 100 | 뜨개 모자·목도리·털실 뭉치(셋) | 2번 |
| cat-maneki | 복 부르는 삼색냥 | legend 150 | 자세·표정이 다름(앞발 손짓·눈웃음) + 몸 전체가 도자기 새 그림 | 3번 |
| cat-calico | 삼색냥 | rare 50 | 무늬 + 방울 목걸이 하나 | 1번 (사용자 추가 요청) |

## 진행 기록

- 생성: `scaffold-skin-batch.py cat yarn|maneki`, 시안을 `ref/design.png` 로 같이 넣음. 복 부르는 삼색냥은 row0 서기 4칸과 row3 c2·c3(손짓 A·B)만 새 자세, 나머지는 기본 자세.
- 채택: 복 부르는 삼색냥 전부 attempt-01. 털실 삼색냥 전부 attempt-02(1차 메인은 털실이 칸 경계를 넘어 Codex 가 다시 그림, sleep·scuffle 은 2차 메인에 맞춰 다시 그림).
- 검증 예외: 복 부르는 삼색냥 r3c2 standing-size 113×131 — 손짓으로 앞발을 든 칸이라 1px 넘음(의도).
- 걷기: 브리프에 "c0·c2 앞발 반대, c1·c3 다른 다리 듦"을 덧붙여 3번씩 그림. 털실은 attempt-01(털실 뭉치를 굴리며 걸음, 3차는 윗몸 3.7px 밀림 FAIL), 복 부르는 삼색냥은 attempt-03(다리 차이 44%/46% 로 가장 확실히 번갈아 걸음).
- 둥둥라이더 hang·blow·fall·poke 8장(날짜 태그 `2026-10-23-calico`): 전부 attempt-01. 복 부르는 삼색냥 hang 은 "넓이 0.76× 서기" 불합격 — 서기 칸이 금화·든 앞발로 커서 생긴 오탐(그림 크기는 털실 hang 과 같음) → `--allow-fail`.
- 삼색냥(레어): 첫 실행이 외부 종료 신호로 끊겨 다시 그림, 시트 3장 attempt-01. multi-run 은 공 위 귀 끝 두 개(의도). 걷기 attempt-03(1차는 같은 걸음 반복 FAIL), 둥둥라이더 hang·blow·poke attempt-01·fall attempt-03.

## 4. 리팩·QA 규칙 (8차에서 확정)

1. 원본은 **평평한 단색 배경**에 1024~2000px 로 생성. 배경색은 캐릭터 팔레트(분홍·빨강·자주)와 먼 색 — **초원과 비슷한 중간 초록(약 RGB 110,190,100)** 권장: 남는 림이 있어도 잔디 위에서 안 보인다. 마젠타·분홍·라벤더 배경 금지.
2. 셀 분할은 **고정 격자 크롭 금지** → 네 모서리 flood-fill 후 8-연결 컴포넌트를 중심점으로 셀에 배정 (H 도구 방식). 셀당 alpha≥8 y-run·x-run 1개(의도된 위성: r0 마크·r4c3 별 제외).
3. 림 despill: 투명에 인접한 2px 띠에서 배경색과 ΔRGB ≤ 40 인 픽셀은 안쪽 이웃 색으로 교체(픽셀 삭제 X). 림 비율 < 1%.
4. 공 정규화: 균등 축소, 높이 112 목표·돌출 포함 폭 ≤120, 중심 (80,80)±2. 찌그러짐 칸은 폭 120. row1 col3 == row2 col0 diff 0. 공 4칸 서로 상이.
5. 접지 셀 마지막 불투명 행 = 149(바닥 y=150). scuffle 화들짝·낙하는 공중.
6. 28px 대조 시트에 기존 9종 + 리본돼지 10마리. 파일명 ↔ 내용 대조, md5 기록, alpha 1~7 = 0.

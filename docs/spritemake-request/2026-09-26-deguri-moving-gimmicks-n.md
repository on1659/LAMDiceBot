## 1. 왜 N차인가

랜덤 맵(2026-09-24~26, `docs/goal/applied/deguri-moving-gimmicks.md`)에서 판마다 가운데 장애물 조합이 바뀌게 됐다. 그중 **움직이는 장애물 5종**이 GPT 토큰이 없던 때라 기존 그림 재활용·코드 도형으로 들어가 있다:

| 장애물 | 지금 모습 | 문제 |
|---|---|---|
| 진자 통나무 | 범퍼 통나무(`log-bumper`) 축소 + 코드 밧줄 + 검은 네모 축 | 매달린 추로 안 읽힘 |
| 밀대(피스톤) | 코드 갈색 네모 + 줄무늬 판자 | 트랙 소품과 화풍이 다름 |
| 트램펄린 | 울타리(`fence-mid`)를 파이썬으로 파랗게 칠한 것 | 울타리처럼 보임, 탄력 천이 아님 |
| 돌풍 | 기존 바람 줄(`wind`) 24개 + "돌풍!" 글자 | 구간 전체에 부는 바람으로 안 읽힘, 방향 알림 없음 |
| 지진 | 코드 선 3줄 금 + 먼지 | 금이 선으로만 보임 |

뽑기 쪽은 **코인** 하나: 지금 공용 UI 아이콘 동전을 가로로 눌러서 "모로 선" 척을 한다. 코인 넣기 연출(한 바퀴 반 뒤집히며 투입구로 들어감)에 쓸 **회전 스트립**을 그린다.

**대포(cannon)·`cannon-smoke` 는 취소**(장애물이 삭제됐다). goal 문서 계약표에 남아 있어도 그리지 않는다.

## 4. 놓이는 자리 (코드 기준, 표시 px)

- 트램펄린: (200,180)→(400,200), (400,380)→(600,360) 두 개, 길이 ≈200
- 돌풍: 구간 150..650 × 높이 560 전부, 풍향계는 구간 오른쪽 위 안쪽(오른쪽 끝 −30, 위 +40)

- 코인: 뽑기 무대 300×420 안에서 지름 ≈29 로 보인다(기계 좌표 36 칸)

## 6. 인수 (LAMDiceBot 세션)

1. `generated/` 원본을 Claude 가 Python(`/opt/homebrew/bin/python3`, Pillow)으로 정규화 → 칸 크기·앵커 맞춤 → `final/` + 게이트(알파 bbox·타일 이음새·칸 수).
2. PNG → webp(`pngquant --quality 65-95` → `cwebp -lossless -z 9`)로 받기 경로에.
3. `js/deguri-render.js` `ASSETS` 에 이름 추가(파일이 있을 때만 — 없는 파일 매핑은 404) + `ASSET_VER` 올림. `trampoline` 은 같은 이름 교체라 `ASSET_VER` 필수. 새 이름 `trampoline-post`·`quake-warn`·`wind-vane` 은 그리기 코드도 추가.
4. 코인: `js/deguri-gacha.js` 코인 그리기를 `UIIcons.draw('coin')` + scaleX 누르기 → 스트립 프레임으로, `ASSET_VER` 올림.
5. `assets/deguri/deguri.manifest.json` 에 N차 섹션(배치·md5).

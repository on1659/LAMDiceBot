## 3. 에셋 목록

### 3-A. 캡슐 세트 — 등급마다 한 장 (3장: rare / epic / legend)

한 장에 **가로 9칸**을 같이 그린다: `닫힘 · 열기1 · 열기2 · 열기3 · 열기4 · 열기5 · 컵 · 뚜껑 · 뚜껑 뒤집힘`.

| 칸 | 그림 지시 |
|---|---|
| 닫힘 | 동그란 가챠 캡슐(지름 = 칸 폭의 75%). **위 반구 = 등급 색**(레어 하늘·에픽 보라·전설 금, 광택), **아래 반구 = 크림색 불투명**, 가운데 이음새는 살짝 튀어나온 **턱 한 줄**. 코드가 이 한 장을 회전시켜 굴린다 → 회전해도 어색하지 않게 |
| 열기1~4 | 꿈틀(살짝 기울기) → 이음새에 금 → 금 사이로 등급 색 빛이 **불투명 색면으로** 샘 → 뚜껑이 들썩 |
| 열기5 | 뚜껑이 떨어져 **컵 옆에 기대 있음**(공중에 뜨지 않음). 빛 새는 효과·파편 없음 — 이 칸만 봐도 "열린 캡슐" |
| 컵 | 아래 반구만. **안쪽이 보이게**(속이 어두운 크림, 테두리 두께 보임) — 동물이 이 컵 위에 선다 |
| 뚜껑 | 위 반구만, 닫힘 칸과 같은 자리·같은 모양. **절단면 쪽 안쪽 테두리**가 보이게 |
| 뚜껑 뒤집힘 | 뚜껑을 180° 뒤집어 안쪽(오목한 면)이 위로 보이는 모습 — 코드가 경첩(컵 왼쪽 가장자리)을 축으로 흔든다 |

- **3등급의 닫힘 실루엣(알파)은 완전히 같아야 한다** — 색만 다르게. 컵은 3등급 공통 크림이라 같은 모양.
- 칸 크기 참고(최종은 Claude 가 맞춤): 닫힘·컵·뚜껑 = 192×192, 열기 = 256×192(뚜껑 자리 때문에 넓음), 캡슐 중심 (96,100), 지름 144, 바닥 172.

### 3-B. 빛살 — 등급마다 1장 (3장)

열린 캡슐 뒤에서 **천천히 도는 후광**. 384×384, 가운데 중심, 회전 대칭(코드가 돌린다).
- 레어: 하늘색 빛줄기 12~16갈래, 끝이 뾰족한 삼각형.
- 에픽: 보라 빛줄기 + 사이사이 작은 별 가루.
- 전설: 금색 굵은 빛줄기 + 짧은 줄기 교대 + 가장자리 반짝 점. 가장 화려하게.
- 가운데 지름 ~90 은 비워 둔다(동물이 선다). 반투명 금지 — 진한 색 테두리 + 밝은 속.

### 3-C. 반짝이 — 1장, 4칸 (96×96 ×4)

결과 화면 동물 주변·투입구에 뜨는 반짝임 루프: `작게 → 크게(네 갈래 별 + 작은 점) → 가장 크게 → 작게`. 금·흰 색, 네 갈래 별 모양이 기본. 칸 가운데 정렬.

### 3-D. 유리구 공 — 1장, 6칸 (가로 스트립)

유리구 안에서 코드가 굴리는 공(로또식). 칸 58×58(화면 29) 기준으로 그린다. 색 순서 **분홍 · 연두 · 파랑 · 보라 · 노랑 · 금**. 광택 점 하나(왼쪽 위), 외곽선, 무늬 없음(회전해도 티 안 나게). 파랑·보라·금은 결과 등급 색(레어·에픽·전설)이라 캡슐 위 반구 색과 맞춘다.

### 3-E. 기계 변형판 — 1장

**레퍼런스 `gacha-machine.webp` 와 같은 기계를 같은 구도·크기로** 다시 그리되 두 가지만 다르게:
1. **유리구 안이 비어 있다**(공 없음, 유리 광택과 바닥만).
2. **유리구 바닥 가운데 조금 왼쪽에서 몸통 안으로 내려가는 짧은 황동 관** — 뽑힌 공이 빨려 들어가는 입구(위에서 보이는 둥근 구멍). 관은 몸통 앞판 뒤로 들어가 배출구 바로 위에서 끝난다.
- 레일·배출구·손잡이 자리·발바닥 엠블럼·코인 투입구(발바닥 오른쪽 금색 슬롯)는 **레퍼런스와 같은 위치**. Claude 가 여기서 빈 유리구 층·레일 앞판·뽑기 아이콘을 오리고 앵커를 다시 잰다.
- 휴지 기계(공 있음)는 새로 그리지 않는다 — 게임은 빈 유리구 위에 공을 코드로 그린다.

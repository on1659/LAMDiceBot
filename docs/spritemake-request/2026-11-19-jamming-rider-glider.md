## A. 행글라이더 — `assets/jamming/glider.webp`

| 항목 | 값 |
|---|---|
| 캔버스 | 128×64 칸 × 6열 × 1행(768×64) |
| 칸 | c0 편 날개(나는 중) · c1 펴지는 1/3 · c2 펴지는 2/3 · c3 접은 자루(어깨에 메는 둘둘 만 날개, 가로로 긴 막대) · c4 구겨진 날개(날개 접힘 tumble) · c5 A자 손잡이 틀만(날개 없이, 몸 앞에 겹쳐 그림) |
| 매다는 점 | 편 날개 칸의 용골 가운데 = 칸 (78, 34) 근처 — 그림에서 다시 재서 `assets/jamming/glider.json` 에 `{ hang: [x, y], keelNose: [x, y] }` 로 적는다(렌더러 `HG.hx/hy` 를 이 값으로 바꾼다) |
| 색 | **흰 바탕 1장 + 코드 착색**: 날개 천은 흰색(밝기만 있는 회색 단계)으로 그리고, 색 칸(코에서 부채꼴로 뻗는 줄 2개)만 순흰으로 남긴다. 렌더러가 참가자 색 15가지(`COLORS`)를 `multiply` 로 입힌다 — 15장 그리지 않는다. 틀·용골은 짙은 금속색(착색 안 됨 — 별도 칸 c5 와 같은 색) |
| 크기 기준 | 편 날개 폭 ≈ 동물 서기 칸 몸 넓이 × 2.4(목업 98px : 몸 50px). 매달린 동물(B)과 겹쳐 그려 비율을 본다 |

## B. 동물 매달린 자세 — `assets/jamming/creatures/{동물}-glide.webp` (기본 10종: hedgehog turtle panda hamster pufferfish raccoon rabbit ribbonpig cat penguin)

| 항목 | 값 |
|---|---|
| 캔버스 | 640×160, 4×1, 칸 160, 오른쪽 향함 |
| 칸 | c0·c1 엎드려 매달림(하네스에 배를 대고 누운 몸, 두 앞발로 머리 위 가로대를 쥠 — 흔들림 2칸) · c2 박차기(날개를 든 채 뒷발로 땅을 차는 순간, 서 있는 몸) · c3 접혀 빙글(몸을 공처럼 웅크림 — 날개 접힘 tumble) |
| 기준점 | 가로대를 쥔 앞발 끝 = 칸 (80, 20) 근처 — `glide-sheet.py hand` 로 재서 렌더러 표에(둥둥라이더 `MOUTH`·`HANG_ANCHOR` 와 같은 방식) |
| 크기 | 몸 넓이 = 기본 시트 row 0 서기 칸 넓이의 중앙값(시트당 배율 1개) — 걷기 시트 `walk-sheet.py` 와 같은 규칙 |
| 금지 표현 | "밧줄에 매달림(hang from a rope)" 은 이미지 도구 안전 검사에 걸린 전례가 있다(둥둥라이더 너구리) → **"행글라이더 가로대를 두 손으로 잡고 엎드려 날아감"** 으로 쓴다 |

- 스킨(`{동물}-{스킨}-glide.webp`)은 기본 10종을 고른 뒤 둥둥라이더 스킨 갈래(recolor·remap·pixelate·dress) 그대로. 없으면 기본 동물 그림 + 스킨 [1,1] 칸으로 대신한다.
- 검증 스크립트를 먼저 만든다(`AutoTest/spritemake/glide-sheet.py` — `walk-sheet.py` 복사: 배경 제거·덩어리 배정·배율·정렬·기준점 재기).

## 시안 단계(사용자에게 먼저 보여 줄 것)

1. A c0(편 날개) 한 장 + B 햄스터 c0 한 장 — 둘을 겹쳐 한 장으로(실제 게임 크기, 폰 375 폭 화면에서 98px 날개 기준 — `feedback_sian_real_stage_size`).
2. 날개 착색 미리보기: 같은 날개에 참가자 색 5가지 입힌 줄.
3. 사용자가 고르면 A 전체 6칸 → B 10종.

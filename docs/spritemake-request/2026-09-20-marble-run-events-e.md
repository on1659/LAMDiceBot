## 1. 왜 5차인가

사용자 플레이 피드백 5건 중 그림이 필요한 것:
- **댐·간헐천이 멈춰 보인다** — 댐은 5프레임을 터질 때 한 번 넘기고 끝, 비버는 2프레임, 물이 없다(수면·흐름 없음), 간헐천 웅덩이는 정지 1장 + 물기둥은 코드 그라데이션. 대기 중 계속 도는 **루프 프레임**이 없어서 정지 화면처럼 보인다.
- **두더지가 고슴도치로 보인다** — 3차 `mole.png` 가 갈색 둥근 몸이라 플레이어 동물(고슴도치)과 구분이 안 됨. 역할("박자대로 올라와 그 순간 머리 위 공만 위로 튕김")이 안 읽힌다.
- 새 장치 2종: **스프링 널빤지**(끊긴 경사로 끝이 시간에 따라 휘었다가 튕겨 공을 위로 되돌려 보냄), **독수리**(결승 구멍밭 앞에서 기다리거나 통로를 걷는 동물을 채 가서 풍차 옆에 떨어뜨림).

코드는 에셋 없이 코드 도형/루프로 먼저 들어가고, 에셋이 오면 그림만 교체한다.

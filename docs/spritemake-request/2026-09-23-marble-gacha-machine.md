모든 그림은 **화면 크기의 2배**로 그린다(예: 기계 512×704 → 화면 256×352).

연출 순서:
1. 기계가 가만히 서 있다(**휴지**). 머리 위 램프는 꺼져 있다.
2. [뽑기]를 누르면 손잡이(크랭크)가 돌고(코드가 회전), 유리구 안 캡슐 더미가 뒤섞이고(**섞기 3프레임**), 기계가 덜컹인다(코드 흔들기).
3. 램프가 **결과 등급 색으로 켜진다**(파랑=레어, 보라=에픽, 금=전설 — 예고).
4. 캡슐 구슬이 배출구에서 나와 나무 레일을 **데굴데굴 굴러**(닫힌 캡슐 한 장을 코드가 회전) 레일 끝 멈춤목에 톡 멈춘다.
5. 캡슐이 화면 가운데로 떠오르며 커지고(코드), 꿈틀→금 가고→빛 새고→뚜껑이 튀어 열린다(**열기 6프레임**).

## 스킵 규칙 (사용자 요구 — 전 부품 적용)

화면 아무 데나 탭하면 그 즉시 **최종 화면**으로 건너뛴다. 최종 화면 = 휴지 기계 + 크랭크 0° + 램프(결과 등급) + 열린 캡슐 마지막 프레임 + 빛살 + 반짝이 + 상품.
연속 뽑기에서는 스킵이 여러 번 연달아 일어난다. 그래서:

1. **모든 움직임에 "멈춘 한 장"이 있고, 그 한 장만으로 완성된 그림이어야 한다.** 휴지 기계, 크랭크 0°, 열기 마지막 프레임(5), 램프 각 등급 칸이 그것이다. 중간 프레임에만 있는 요소(뚜껑, 컵 모양 등)가 없어야 한다.
2. **휴지 기계에 캡슐을 구워 넣지 말 것.** 레일·배출구는 비어 있다(캡슐은 따로 얹는다 — 안 그러면 스킵 화면에 캡슐이 둘 보인다).
3. **섞기 프레임은 유리구 안쪽만 다르다.** 유리구 밖 픽셀은 휴지와 1픽셀도 다르면 안 된다(리팩에서 강제 — 휴지 외부를 그대로 덮어쓴다). 그래야 어느 프레임에서 끊어도 튀지 않는다.
4. **열기 마지막 프레임(5)은 앞 프레임 없이 단독으로 봐도 "열린 캡슐"로 읽혀야 한다.** 뚜껑이 공중에 떠 있으면 안 되고, 컵 옆에 기대 있거나 뒤로 넘어가 있다. 빛 새는 효과·조각 파편은 5번에 넣지 않는다.
5. **모션 블러·잔상·속도선을 어떤 프레임에도 굽지 말 것.** 스킵으로 멈춘 화면에 남는다. 속도감은 코드가 낸다.
6. 등급 3종 캡슐의 **실루엣(알파)은 완전히 같다** — 코드가 등급과 무관하게 같은 좌표·같은 타이밍으로 그리고, 스킵 시 등급만 바꿔 끼운다.

## 제작 방법 권장

1. **기계 휴지 한 장을 먼저 끝낸다** — 이 배치의 중심. 큰 캔버스에서 여러 번 시도하고 가장 좋은 걸 고른 뒤 512×704 로 정규화(최근접 이웃, 한 배율). 이게 확정되기 전에 다른 파일로 넘어가지 말 것.
2. 섞기 3칸·램프 4칸 = 휴지를 edit target 으로, 유리구 안 / 램프만 바꾸라고 지시 → 리팩이 영역 밖을 휴지로 덮는다.
3. lip = 휴지에서 마스크로 잘라낸다(생성 아님).
4. 크랭크 = 휴지를 style reference 로 따로 생성(황동·크림 손잡이 알, 몸통 받침판과 같은 색).
5. 캡슐은 **이미지 도구로 도트 그림**(동물과 같은 외곽선·음영 — 코드로 그린 납작한 원 금지). rare 닫힌 캡슐 → open 칸을 edit 로. epic/legend = rare 각 칸을 edit target 으로 색·무늬만.
6. 빛살 = 코드로 생성해도 된다(기하 도형이라 결정론 생성이 더 정확). 반짝이도 코드 가능. 단 화풍(외곽·도트 크기)은 맞출 것.

## 판정 (Codex 자체 QA + 사람 판정 기준)

자동 게이트(리팩/QA 도구에 넣을 것):
- 캔버스·칸 크기, 하드 알파(0/255 외 0개), 여백 4px, 앵커 목표 ±12px
- 섞기 3칸: 유리구 원 밖 픽셀 == 휴지 (차이 0)
- 램프 꺼짐 칸 == 휴지의 램프 상자 (차이 0)
- 휴지 프레임에서 레일 경로(캡슐 경로 선 ±36 띠)와 배출구 구멍 안에 캡슐 색 픽셀 없음
- 캡슐: 등급 3종 알파 == rare 알파, 닫힌 캡슐 == open 0칸, open 5칸의 금지 상자 비어 있음
- **기계 실루엣 연결성**: 휴지 기계의 불투명 픽셀 99% 이상이 8-연결 한 덩어리, 실루엣 안에 가로로 관통하는 투명 줄 없음(1차 흰 틈 사고)
- 빛살: 30° 회전 후 알파 IoU ≥ 0.9
- 전 파일 md5/sha256 매니페스트

사람 판정(축소본으로 볼 것 — 기계 256×352, 캡슐 72·48px, 초록 `#8fd07a`·하늘 `#bfe7ff`·어두운 `#1f2937` 배경 셋):

- 캡슐 3등급이 48px 에서 색만으로 즉시 구분되는가
- open 5칸만 떼어 봤을 때 "열린 캡슐 + 기댄 뚜껑"으로 읽히는가

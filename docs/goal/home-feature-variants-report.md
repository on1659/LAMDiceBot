# 홈 목업 12~14 — 기능을 빠뜨리지 않는 간결한 탐색

## 작업 기준

- 사용자 승인 흐름: 서버 선택 → 로비 → 작은 ‘게임 만들기’ → 게임 선택 → 방. 첫 방문자만 이름 확인.
- 11번의 차분한 색, 짧은 한국어, 픽셀 아이콘, 모바일·PC 대응을 유지한다.
- 12번: 상단 메뉴와 로비의 직접 랭킹 버튼. 13번: 엄지로 접근하는 하단 내비게이션. 14번: 선택한 모임 안에서 방·기록을 전환하는 탭.
- 랭킹·업데이트뿐 아니라 현재 사용자 기능의 진입 위치를 소스에서 확인하고 공통 기능 목록으로 대조한다. 계정·서버 관리자·방장 권한을 구분한다.
- 각 목업은 독립 HTML 한 파일이며 예시 데이터만 조작한다. 운영 API·계정·서버를 변경하지 않고 게임 결과를 생성하지 않는다.
- 기존 1~11과 운영 코드는 수정하지 않는다. 허브에는 12~14를 추가한다.

## 검증

375×812와 1200×900, 라이트·다크, 처음·단골·로그인·관리자 상태를 확인한다. 첫 화면 글자·조작 수는 기존 측정기로 기록하고, 실제 기능은 직접 클릭으로 확인한다. 추가 기능은 이름뿐인 버튼으로 두지 않고 예시 화면이나 동작을 제공한다.

### 재현 범위

- 독립 HTML의 예시 상태다. 운영 API, 계정, 가입 승인, 채팅, 주문, 게임 결과를 변경하지 않는다. 데이터와 로그인은 새로고침하면 초기화되며 예시 닉네임만 브라우저에 저장한다.
- 방 제목·비공개 설정은 방에 들어간 후 `방 설정`에서 보는 제안 흐름이다. 실제 제품의 생성 폼/게임별 편집 지원을 그대로 복제한 것이 아니다.
- 실제 멀티플레이, 결과 계산, 접속/재접속, 만료 타이머, 탈것 15종 전체, 준비 순서 드래그, 임의 시각 예약, 상세 주문 메뉴 관리, 결과 재생, 꾸미기 구매·뽑기는 실제 게임 링크로 연결한다. 목업에서 완전히 재구현했다고 주장하지 않는다.
- 경마 `/horse-race`, 주사위 `/game`, 룰렛 `/roulette`, 데구리 `/deguri`와 기존 `/pages/` 문서는 `https://lamdice.com` 새 창으로 연결한다. 이 링크는 현재 예시 방을 실제 방으로 이전하지 않는다.
- 소리는 설정 UI만 있고 재생하지 않는다. 이전 기록 삭제는 확인 화면 예시다. 자유 사람 랭킹은 현재 기록 경로에 맞춰 빈 상태, 탈것 통계는 전체 누적으로 표시한다.
- 서버 참여 초대는 예시 `우리팀`의 코드 2468로 입장하면 대상 방을 유지한다. 실제 비동기 관리자 승인·네트워크 실패는 연동하지 않는다.

### 검증 결과

- `node mockups/measure.js 12 13 14`: 처음 화면 모두 **56자 / 조작 6개 / 1화면**. 375×812, 공백 제외, 목업 조작 바 제외. 펼친 메뉴·팝업에는 이 제한을 적용하지 않는다.
- 클릭 검증: 세 안 × 모바일 375×812 / PC 1200×900 = **6조합 통과, JS 오류 0**.
- 처음/단골/로그인 → 서버 → 생성 → 4개 게임 선택, 열린 방 합류와 복귀, 메뉴 항목, 랭킹 정렬/달력/메뉴, 6스킨/음소거, 채팅의 입력 문자열 처리, 주문 마감, 방 설정/준비, 공유 미지원 안내, 서버 검색/신청/코드 오류와 성공, 초대 복귀, 관리자 승인/새 시즌/새 서버 관리 확인.
- 라이트·다크 로비, 첫 화면, 달력, 방 화면 스크린샷 검토. 주요 화면 가로 넘침 없음, 표시된 이미지 정상 로드. 실제 공유 OS 창과 운영 페이지 네트워크는 자동 검사하지 않음.
- 생성 탭 수: 첫 방문 4번, 이름 저장/로그인 3번. 합류는 각각 3번/2번. 서버 우선이라는 사용자 결정에 따른 값이다.
- 독립 검토에서 통합 랭킹 합산, 지난 시즌 메뉴 안내, 달력 게임 필터, 서버 초대 문맥을 수정했다. 본 파일들은 공용 게임 코드에 영향을 주지 않는다.

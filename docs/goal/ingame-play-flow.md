# 인게임 조작 흐름 개선

2026-10-08. 사용자는 편의성을 개선하되 외곽뿐 아니라 게임 내부 환경이 핵심이라고 명시했다.

## 완료 기준
- 대기 화면에서 선택·준비·시작에 바로 접근한다. 모바일375×812에서 준비/시작 조작은 첫 화면에 보인다.
- 게임 내부에 내 선택/현재 할 일/진행 상태를 실제 상태에 맞게 표시한다. 주사위 굴리기, 룰렛 참여 확인, 경마 트랙 선택, 데구리 동물/출발 위치 안내를 개선한다.
- PC는 게임과 채팅을 함께 표시한다. 모바일은 고정 조작줄에서 채팅/주문 패널을 열고 원래 화면으로 복귀한다.
- 대기/진행/결과 상태는 기존 게임 상태에서 결정한다. 재접속과 다음 판도 같은 규칙을 따른다.
- 게임 결과, 렌더 물리, 기존 초대·호스트 권한·준비 드래그·전체화면·주문 기능을 보존한다.
- 광고 슬롯은 유지하되 인게임 고정 조작/입력과 겹치지 않도록 일반 흐름에 배치한다.

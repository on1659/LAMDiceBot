# 모바일 첫 진입 화면 개선

2026-10-13 사용자 피드백: 테스트 서버에 처음 들어갔을 때 모바일 버전처럼 느껴지지 않았다.

## 범위

- `/mobile` 로비 첫 화면을 승인한 모바일 게임 화면의 서체·색 토큰·간격으로 통일한다.
- 지원 게임 네 개를 첫 화면에 직접 보여주고 기존 `.tile` → `go` → `handoff` 연결을 재사용한다.
- 광고·열린 방 목록·랭킹·기록·계정·서버 선택 기능을 유지한다. 광고는 게임 선택 뒤에 둔다.
- 처음 방문할 때 서버 선택을 자동으로 강제하지 않는다. 기존 서버·로그인 복원은 유지한다.
- 이번 피드백은 실제 모바일 UI 적용 후속 수정이다. 기존 R&D 목업 파일과 게임 결과·서버 계약은 수정하지 않는다.
- 테스트 서버 feature/marble-run에만 배포한다.

## 완료 기준

- 375×812 첫 화면은 게임 네 개와 서버·메뉴 총 여섯 조작 요소, 60자 이하를 목표로 실측한다.
- 320/375px 라이트·다크에서 가로 넘침 없이 네 게임을 식별하고 누를 수 있다.
- 돌아온 사람은 게임 선택 한 번, 처음 온 사람은 이름 한 번을 추가해 실제 방으로 이어진다.
- 서버 선택·메뉴·계정·테마·기존 방 목록 접근을 유지한다.
- CSS 색 토큰 검사·JS 문법·diff 검사를 통과하고 배포 후 공개 첫 화면을 확인한다.

## 검증

- 로컬 `node mockups/measure.js --url http://127.0.0.1:43119/mobile`: 처음 방문 33자 / 조작 요소 6개, 통과.
- 브라우저 320·375px 라이트·다크에서 네 게임 표시, 가로 넘침 없음 확인.
- 저장된 이름으로 경마·주사위·룰렛·데구리 각 1탭 실제 방 생성 및 퇴장 확인. 새 출처에서는 게임 선택 → 이름 입력·들어가기 → 실제 경마 방으로 연결 확인.
- 메뉴 → 계정·화면 설정, 하단 서버 선택, 스크롤 후 열린 방 새로고침 접근 확인.
- `node --check js/mobile-home.js`, `node AutoTest/check-hardcoded-colors.js`, `git diff --check` 통과.
- 휴대폰 실기기 확인은 별도이며, 이번 검증은 브라우저의 모바일 크기에서 수행했다.

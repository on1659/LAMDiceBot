# 승인한 모바일 목업을 실제 게임에 적용

2026-10-12 사용자 명시 요청: 현재 승인한 목업을 실제 게임 화면에 적용하고 테마를 통일해 테스트 서버에 먼저 배포한다.

## 범위와 계약

- 지원 게임 주사위·룰렛·경마·데구리의 실제 준비/진행/결과 및 주문·채팅·메뉴.
- 이번 요청은 목업 비교가 아닌 실제 게임 적용 단계다. 사용자 명시 승인에 따라 게임 HTML과 모바일 표현 모듈/CSS를 수정한다.
- 서버 결과·소켓 이벤트·권한·준비/주문 계약과 원본 캔버스를 유지한다. 목업의 고정 예시 데이터를 게임에 넣지 않는다.
- 6개 기존 테마는 ThemeModule과 css/theme.css 토큰을 사용한다. 목업 전용 저장키나 파일에 의존하지 않는다.
- PC 화면과 전체화면/리플레이/꾸미기 기능을 유지한다. 미지원 게임은 범위에서 제외한다.
- main은 수정/푸시하지 않는다. feature/marble-run → lamtest.up.railway.app만 배포한다.

## 적용 방향

- 동일한 72px 방 헤더, 52px 주요 버튼, 게임/주문/채팅/메뉴 하단 탭.
- 실제 게임 컨트롤을 재사용하고 탭별 일반 화면에 표시한다.
- 선택 캐릭터·게임판·당첨 결과를 강조하고 선택 체크와 간격을 목업에 맞춘다.
- 데구리는 세로 전체 너비, 아래 스크롤과 기존 터치 조작을 유지한다.

## 완료 기준

- 320/375px 라이트·다크 및 6스킨 확인. PC 회귀 확인.
- 2명 이상의 실제 연결로 네 게임의 준비→진행→결과→재준비 검증.
- 게임/주문/채팅/메뉴 이동, 주문/채팅 서버 동기화와 방장/참가자 권한 유지.
- 캔버스 노드와 치수가 탭 왕복·화면 크기 변경 후 유지된다.
- JS/인라인 스크립트 문법·색 검사·관련 기존 자동검증 통과.
- 테스트 배포 성공과 실제 게임 공개 주소 표시 확인.

## 검증 기록

- 로컬 실제 서버에서 게임별 2개 소켓 연결로 준비→시작→서버 결과→다음 판 재준비 확인. 주사위 범위 6/1000 및 룰렛 결과 위조·참가자 권한 거부도 기존 계약대로 통과했다.
- 실제 브라우저에서 네 게임의 원본 버튼·캔버스·결과창·주문 저장·채팅과 탭 이동 확인. 주사위 두 판의 서버 기록과 모바일 결과 카드가 일치했다.
- 320/375px 가로 넘침 없음. 데구리 캔버스는 320×569 / 375×667이며 좌우가 뷰포트에 맞는다. 원본 전체화면 320×812 및 PC 복귀 후 원본 화면 복원 확인.
- 공통 테마 선택기로 light/dark/black/midnight/mocha/purple 전환 확인. 주문 초안과 원본 입력 ID는 탭 왕복·PC 복귀 후 유지된다.
- JS 및 네 HTML 인라인 스크립트 문법, CSS 괄호, 새 하드코딩 색 검사, git diff --check 통과. `node mockups/measure.js 10`도 기존 홈 목업 기준 통과(30자/6컨트롤).
- 브라우저 뷰포트와 원본 전체화면 조작으로 검증했다. 실물 휴대폰의 핀치 제스처는 별도 확인이 필요하며 기존 터치 핸들러를 유지했다.
- 배포 대상은 feature/marble-run의 테스트 서버이며 배포 후 공개 실제 게임 화면에서 새 자산과 모바일 UI를 확인한다.

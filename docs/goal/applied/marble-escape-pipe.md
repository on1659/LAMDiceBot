# 마블런 — 탈출 파이프

작성 2026-09-20 밤. 사용자 결정: Fable 세션 제안(지형 대신 규칙) 중 탈출 파이프 채택, 구현은 "두 맵 통합" 세션(Opus) 단독.

## 왜

⑦-c 갈래 골짜기까지 넣고 보니 새 구간(끊긴 경사·범퍼 밭·봉우리·그릇)이 전부 "튕겨서 흩어짐"이라 관전자에게 같은 장면의 반복. 꼴찌 뽑기 게임은 "누가 아직 트랙에 남았나"가 이야기여야 한다. 지형을 더 만들지 말고 **남은 놈이 구간마다 줄어드는 규칙**을 하나 넣는다.

## 규칙 (확정 규칙에 예외 하나 추가)

- 도착 = 통로 끝 골 진입 **또는 탈출 파이프 진입**. 순위 = 도착 순서. 꼴찌 = 마지막 도착 (변동 없음).
- 파이프에 빨려 들어간 동물은 그 순간 순위가 확정되고, 땅속으로 스탠드 홈통까지 이동해 자기 자리에 앉는다(연출).
- 파이프마다 **정원**이 있다: 전체 정원 = `floor(공 수 × ESCAPE_RATIO(0.3))`, 파이프 5개에 라운드로빈 배분. 차면 뚜껑이 닫힌다(처음부터 0이면 닫힌 채 시작). 2마리(2명·조금)면 정원 0 → 파이프 없는 경주와 같다.
  - 근거: 정원이 없으면 200마리가 대량 이탈하고, 소인원에선 한 마리 이탈이 곧 결과라 긴장이 사라진다. 최소 70%는 골까지 간다 → 꼴찌는 항상 통로 골 진입으로 결정.
- 파이프 자리(시드로 x 흔들림):
  - 상단 2개: 풍차 아래·두더지 경사로 위 (y 2620) 좌우 — 풍차에 튕겨 옆으로 간 놈이 먹힌다
  - 하단 3개: 갈래 골짜기 범퍼 밭 자리 (V+450) — 범퍼 밭은 파이프 밭으로 교체
- 물리: 입구 폭 40(공 1.4개), 양옆 짧은 기둥(12px). 공 중심이 입구 띠에 들어오고 정원이 남았으면 즉시 도착(`escape` 이벤트 → `finish`). 찼으면 그냥 지나친다.

## 파일

- `socket/marble-sim.js` — 상수 `PIPE_*`, `buildTrack` 조각 `pipe {x, y, w, cap}`, simulate 캡처 루프, 이벤트 `escape`
- `js/marble-render.js` — 파이프 입구(코드 도형: 어두운 타원+테두리+남은 자리/닫힘 라벨), 빨려 들어가는 fx, 스탠드 홈통 출발을 `PIPE_TRAVEL_MS` 지연, 미니맵 점
- `marble-multiplayer.html` — render `?v` 증가
- 에셋: 파이프 입구 1장 후속 의뢰(코드 도형으로 먼저)

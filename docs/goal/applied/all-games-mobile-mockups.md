# 전 게임 모바일 목업

사용자가 승인한 경마 모바일 목업 스타일로 주사위·룰렛·데구리·사다리·회전 칼날의 준비/진행/결과를 만든다. 기존 경마와 함께 6종 비교 화면에서 진입한다.

- 새 목업 파일만 작성. 기존 실제 게임, 서버, 공용 게임 JS/CSS를 수정하지 않는다.
- 테마 6종과 모바일 방 헤더·하단 메뉴를 통일한다.
- 고정 예시 데이터만 사용하고 실제 결과를 생성하거나 서버에 접속하지 않는다.
- 준비 → 진행 → 결과 → 다시 준비가 연결되고 게임별 선택이 페이지 안에서 유지된다.
- 주문·채팅·메뉴는 기존 목업을 재사용하고 선택한 게임으로 돌아온다.
- 320/375px 화면, 라이트/다크, 이미지 로드, 기본 조작을 확인한다.
- `node mockups/measure.js --url ...`로 읽을 양을 측정한다. 홈 전용 60자/6조작 기준은 인게임의 합격 기준으로 적용하지 않는다.

완료 조건: 6게임 비교 페이지, 5게임의 3단계 화면, 테마 유지, 모바일 검증, 실제 게임 변경 0건.

## 완료 및 검증 (2026-10-12)

- `/mockups/games-mobile.html`: 기존 경마 포함 6종, 단계별 바로가기.
- 새 게임은 `/mockups/{dice,roulette,deguri,ladder,spin-arena}-mobile.html?stage=ready|playing|result`.
- 공통 셸은 `mockups/game-mobile-core.js`/`.css`. 기존 경마 목업 주문·메뉴·테마 파일에 목업 게임 문맥만 연결.
- 브라우저 60조합(5게임 × 3단계 × 320/375px × 라이트/다크): 가로 넘침·깨진 이미지·제목/주요 버튼 누락 0건.
- 6스킨 표면 색·링크 동기화, 메뉴 왕복 게임/단계/테마, 주사위 하이/로우, 데구리 동물/순위, 사다리 빈 당첨, 칼날 외형 유지 및 참여자 시트 확인.
- 룰렛 회전 후 포인터=민지, 사다리 2번→1번 당첨, 데구리 마지막 도착 순서와 결과 일치.
- JS 및 HTML 인라인 스크립트 문법·정적 에셋·색 토큰 검사 통과. `git diff --name-only` 빈 결과로 실제 게임 변경 없음 확인.
- measure.js 준비 화면 결과(글자/조작): 주사위90/11, 룰렛76/8, 데구리98/14, 사다리88/13, 회전 칼날81/10. 이 수치는 홈 전용 합격 기준으로 해석하지 않는다.
- 모바일 결과/설정이 가려진 사다리·데구리·룰렛·칼날은 보드와 간격을 줄여 재확인했다.

## 사용자 범위 정정 (2026-10-12)

현재 지원하는 주사위·룰렛·경마·데구리 4종만 목업 대상이다. 사다리·회전 칼날은 비교 목록에서 제외하며 후속 작업 대상에서도 제외한다. `games-mobile.html`은 디자인 검토용 링크 모음이며 실제 홈·로비·게임 선택 UI가 아니다. 화면 제목·상단·하단에 서비스 미노출임을 명시했다.

## 데구리 화면 방향 정정 (2026-10-12)

데구리 준비·진행 보드는 9:16 세로 비율을 유지하면서 게임 화면 좌우를 전부 채운다. 아래는 main 영역의 세로 스크롤로 보고 확대·축소는 브라우저 기본 터치 핀치를 허용한다(`touch-action: pan-y pinch-zoom`, viewport 확대 제한 없음). 동물/장애물은 보드 너비에 비례하고 준비 설정은 보드 위에 둔다. 320/375px 및 라이트/다크 8조합에서 보드 너비=화면 너비, 가로 넘침 없음, 하단 주요 버튼 고정 확인. 네이티브 두 손가락 제스처 자체는 데스크톱 브라우저 도구로 직접 재현하지 않았다.

# 마블런 — 워프 파이프 (탈출 파이프 대체)

작성 2026-09-20 밤. 사용자 결정: 탈출 파이프(땅속으로 사라져 안 보임)를 버리고 마리오식 워프 파이프로.

## 규칙
- 갈래 골짜기 끊긴 경사로 아래에 파이프 6개가 한 화면에: 윗줄 [1][2][3] / 통나무 한 줄 / 아랫줄 [4][5][6]. 짝 1↔6·2↔5·3↔4(대각선 교차, 같은 색 띠).
- 입구(폭 40)에 들어가면 0.35s 뒤 짝 파이프에서 위로 뿅(트랙 가운데 쪽으로 살짝). 윗줄로 들어가면 범퍼를 건너뛰고 반대편으로(지름길), 아랫줄로 들어가면 윗줄로 되돌아가 범퍼를 다시(손해).
- 도착·순위 규칙 예외 없음(도착 = 통로 끝 골, 꼴찌 = 마지막 도착). 워프는 위치 이동뿐.
- 무한 핑퐁 방지: 공 1마리당 파이프 1회(들어간 것·나온 것 둘 다 소진). 이미 쓴 파이프에 떨어지면 몸통을 지나 아래로 빠진다.
- 기둥·통나무 간격 ≥ 44(공 28 + 여유) — 좁으면 공이 쐐기로 끼어 캡.

## 파일
`socket/marble-sim.js`(WARP_* 상수, 조각 `warp`, 상태 'warp', 이벤트 warp/warpOut), `js/marble-render.js`(파이프는 공 위 레이어 drawBasketFront, 흡입/뿅 fx, 미니맵), `marble-multiplayer.html` ?v. 에셋 `warp-pipe` 는 5차 의뢰(녹색 1장, 색 띠는 코드 틴트).

## 검증
determinism ALL PASS · 4~200마리 경계 스캔 0건 · 시드 스윕(2·24·200마리) 캡 0 · 프리뷰(들어감·짝에서 뿅) 스크린샷.

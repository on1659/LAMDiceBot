## 2. 23 달리기 시뮬 (경주 단계)

- 참가자 4명(라온·나 / 민지 / 준호 / 넷째)의 탈것이 실제 경마 그림 `/assets/horse-race/vehicles/{id}/base-run-{1,2}.webp` 로 달린다(두 장 번갈아). 결승 뒤 `finish`, 결과에서 1등 `victory`, 꼴등 `dead` 등 실제 상태 그림 사용.
- 규칙은 원본 그대로 **꼴등 당첨**. 결과 화면의 순위·당첨자는 시뮬 결과에서 나온다(고정 "오늘은 민지!" 대체).
- 판마다 씨앗(판 번호)으로 정해지는 의사난수(mulberry32 등). `Math.random()` 금지. 같은 판은 언제 봐도 같은 결과, "다음 판"은 다른 결과.
- 8~12초, 구간마다 속도가 바뀌어 역전이 생긴다. 진행 중 현재 순위 표시. 경주 중 `MockAds.setRaceRunning(true)`.
- 목업 바 `결과` 를 바로 누르면 같은 씨앗으로 즉시 계산한 결과를 보여 준다.
- 움직임 줄이기 설정이면 애니메이션 없이 결과로.

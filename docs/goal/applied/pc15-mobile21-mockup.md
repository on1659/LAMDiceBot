# PC는 15, 폰은 21 — 홈·게임방 반응형 목업 (22·23)

2026-10-05. 사용자: "15/21번 같은 느낌 좋은데 PC/모바일 버전으로" → 확인 결과 **넓은 화면은 15번 느낌, 폰은 21번 느낌**, **홈 + 게임 안 둘 다**.

## 산출물

| 파일 | 화면 | PC (≥721px) | 폰 (≤720px) |
|---|---|---|---|
| `mockups/22.html` | 홈(서버·열린 방·기록) | 15번 그대로 (청회색 작업대 3단) | 18번 정보 구성 + 21번 겉모습 |
| `mockups/23.html` | 게임방(준비·선택·경주·결과) | 19번 그대로 | 21번 그대로 |

- 독립 목업. 운영 HTML/CSS/JS/소켓, 기존 목업(15·18·19·21)은 수정하지 않는다. 허브 `mockups/index.html` 등록은 마지막에 한 번.
- 홈의 경마 방 줄("점심 한 판") → `/23`, 게임방 상단 모임 이름·로고 → `/22`. 두 파일이 한 세트로 오간다.
- 목업 바(`#mockBar`)에 `22 홈 · 23 게임방` 전환 + 원안 링크(22: 15·18 / 23: 19·21) + `목록(/main)`.

## 21번 느낌(폰)이란

21.html 의 토큰을 그대로 쓴다(라이트·다크 둘 다): 크림 바탕 `#f2f0eb`/`#faf9f6`, 숲색 `#193d35` 띠, 라임 `#c8f767` 주 버튼, 연두 원형 보조 버튼(초대·메뉴), 반경 24~28px 둥근 카드, 숲색 머리띠 + 라임 번호 배지, **스크롤 밖 하단 고정 라임 주 버튼**(+ 게임방은 하단 도구 줄), safe-area 여백.

## 지킬 것

- PC 화면은 원본(15 / 19)과 1200·1440px 에서 눈으로 구분 안 될 만큼 같게. 바뀌는 건 폰 쪽뿐.
- 폰은 정보·기능을 빼지 않는다(18번에 있는 서버 전환·열린 방·게임 만들기·랭킹·멤버·기록·업데이트, 계정·서버 시트 전부). 겉모습만 21번으로. 글자·조작 요소를 18번보다 늘리지 않는다.
- 고정 예시 데이터만. API·Socket.IO 호출, 결과 계산, `Math.random()` 없음. 채팅 입력은 글자 그대로 표시(escape).
- 다른 사람의 탈것 선택은 경주 전까지 숨김(23, 원본 계약 유지).

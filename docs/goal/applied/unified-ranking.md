# goal: unified-ranking

## One-line Goal
랭킹 팝업의 "종합 / 게임별" 분리를 없애고 **통합 랭킹 하나 + 게임 필터**로 바꾼다. 달력 칸에는 이름 앞에 그 날 가장 많이 당첨된 게임 아이콘을 붙인다.

## Background
지금 팝업은 탭 줄이 4개 겹친다(종합/게임별 → 순위/참여 → 게임 칩 → 경마 순위/탈것 통계). 목록도 승리·승률·평균 등수·참여로 4개다.
사용자 요청(2026-10-04): "게임별 랭킹을 하나로 합치고, 달력엔 사람 앞에 게임 아이콘(무슨 게임에서 가장 많이 걸렸는지), 필터로 특정 게임만도 볼 수 있게. UI/UX 가 핵심."
목업(대화 안 위젯)으로 구조를 보여주고 아래 결정을 받았다.

## 사용자 결정 (2026-10-04)
| 항목 | 결정 |
|------|------|
| 용어 | **당첨** — "승리" 표기를 전부 "당첨"으로 (달력의 "당첨자"와 통일) |
| 평균 등수 | **뺀다** — 게임마다 등수 범위가 달라 합치면 뜻이 흐려짐 |
| 주문(인기 메뉴·내 TOP 메뉴) | **별도 탭** — [순위 / 달력 / 메뉴]. 메뉴 탭에선 게임 필터를 숨김 |
| 순위 줄 표시("전체"일 때) | **A안: 아이콘 + 막대** — 아이콘 = 그 시즌 가장 많이 당첨된 게임, 막대 = 게임별 당첨 비율 |
| 디자인 톤 | **사이트 스킨을 따라간다** — 고정 남색 팝업·보라 그라디언트 헤더·금색 글자를 버리고 공통 토큰(`--bg-white`·`--gray-*`·`--purple-*`·`--fill-brand`)으로. 메달·게임 막대만 `--rank-*` 토큰(라이트·다크) |

## 화면 구조
```
헤더 (← 랭킹 · 시즌 N, 방장이면 새 시즌 버튼)          ← 기존 유지
시즌 선택 줄 (시즌 2개 이상일 때)                       ← 기존 유지
[순위 | 달력 | 메뉴]   보기 전환 — 보기 1개뿐이면 숨김(자유 랭킹)
[전체] [주사위] [경마] …  게임 필터 — 기록 있는 게임만, 메뉴 보기에선 숨김
(경마 필터 + 순위 보기일 때만) 시즌 우승 탈것 줄
본문
```
- **순위 보기**: 정렬 3개(당첨 많은 순 / 당첨률 / 참여 많은 순) + 목록 하나. 1~10등, 내가 10등 밖이면 구분선 뒤에 내 줄.
  - 당첨률은 그 필터에서 5판 이상인 사람만(기존 승률 규칙).
  - "전체"일 때만 이름 앞 게임 아이콘 + 이름 아래 비율 막대 + 범례 한 줄. 게임 하나를 고르면 이름·숫자만.
  - 대표 게임(아이콘) 동률 → 참여 많은 게임 → 고정 게임 순서.
  - 경마 필터 + 현재 시즌이면 목록 아래 "탈것 통계" 펼치기(기존 표 그대로). 탈것 통계는 배포 전역 누적이라 지난 시즌 보기에선 숨김.
- **달력 보기**: 기존 달력 + 칸의 이름 앞에 게임 아이콘.
  - 아이콘 = 그 사람이 **그 날** 가장 많이 당첨된 게임. 동률이면 그 날 먼저 당첨된 게임.
  - 게임 필터를 고르면 아이콘을 뺀다(전부 같은 아이콘이라 이름 칸만 좁아짐).
  - 날짜 상세: 맨 위에 사람별 요약(아이콘 + 이름 + N회, 많은 순) → 그 아래 1차·2차 판 목록(기존).
- **메뉴 보기**: 기존 주문 화면(내 TOP 메뉴·인기 메뉴). 주문 기록 있는 서버에서만.
- 팝업은 어느 게임 방에서 열어도 "전체·순위"로 시작한다(통합 랭킹이 기본).
- 가로 스와이프: 순위 → 옆 게임 필터, 달력 → 달 이동(기존).

## API 변경
- `GET /api/ranking/:serverId`, `GET /api/ranking/free` → `{ serverType, currentSeason?, players, vehicles, orders }`
- `GET /api/ranking/:serverId/season/:season` → `{ season, players }`
- `players = [{ name, byGame: { [gameType]: { games, wins } } }]` — 사람×게임 집계 한 번(`GROUP BY user_name, game_type`).
  필터·정렬·등수·내 순위는 클라가 계산한다. 서버 멤버 규모(수십 명)라 전부 내려도 작다. 자유 랭킹(`server_id IS NULL`)은 기록 경로가 없어 사실상 비어 있다.
- 없어지는 것: `overall`·`dice`·`horseRace`·`roulette`·`ladder`·`spin-arena`·`pirate`·`deguri`·`myRank` 키, `getOverallRanking`·`getGameRanking`·`getHorseRaceStats`·`getMyRank`·`getSeasonRanking`.
- 유지: 달력·시즌 목록·시즌 우승 탈것·새 시즌 라우트, `getTop3Badges`(채팅 배지 — 게임별 기준 그대로).

## Out-of-scope
- DESIGN.md 종이 전단지안 적용 — 홈·로비 범위이고 아직 확정 전. 팝업은 지금 운영 중인 사이트 톤(스킨)에 맞춘다.
- 채팅 TOP3 배지 기준 변경.
- DB 스키마 변경 없음.

## Acceptance Criteria
- [ ] 탭 줄이 [보기 전환] + [게임 필터] 2줄뿐이다. 종합/게임별·순위/참여·경마 서브탭 칩이 없다.
- [ ] 순위 목록 하나에 정렬 3개가 동작하고, "승리"·"평균 등수" 문구가 팝업 어디에도 없다.
- [ ] "전체" 순위 줄에 대표 게임 아이콘과 비율 막대가 보이고, 게임 필터를 고르면 사라진다.
- [ ] 달력 칸 이름 앞에 그 날 최다 당첨 게임 아이콘이 붙고, 필터를 고르면 아이콘 없이 그 게임 판만 센다.
- [ ] 날짜 상세에 사람별 요약 줄이 판 목록 위에 있다.
- [ ] 경마 필터에서 탈것 통계를 펼칠 수 있고 시즌 우승 탈것 줄이 경마 필터에서만 보인다.
- [ ] 메뉴 탭에서 기존 주문 화면이 나오고 게임 필터가 숨는다.
- [ ] 지난 시즌 선택 시 같은 구조(필터·정렬·달력)로 그 시즌 기록이 보인다.
- [ ] 모바일 375px·PC 카드, 라이트·다크 스킨 모두 깨지지 않는다. `node -c` 통과.

# 인게임 재설계 검증

2026-10-07. 작업 브랜치 `feature/home-proto`. 배포 대상은 테스트 `feature/marble-run`; main은 대상이 아니다.

## 변경
- 주사위·룰렛·경마·데구리를 실제 게임판 중심으로 재배치했다. PC는 오른쪽 조작 패널, 모바일은 게임판 다음 조작 패널이다.
- 방 정보는 짧은 헤더/초대 버튼/도구 메뉴, 채팅·기록·주문은 기존 DOM을 보존한 탭이다.
- 주사위 중앙 버튼은 실제 기존 굴리기 핸들러를 사용한다. 중앙 결과 숫자는 기존 연출 텍스트를 따라가 최종 숫자를 먼저 공개하지 않는다.
- 호스트의 준비 드래그 영역을 보존했다. 게임 결과/소켓/물리 계산은 변경하지 않았다.

## 검증 결과
- 네 게임 실제 2인 입장/초대/준비/시작/완주 통과. 주사위 중앙 숫자와 서버 최종 기록 일치.
- 375px/1280px × 라이트/다크 × 네 게임 16개 화면: 가로 넘침 없음, 게임 시작 위치160px 미만, 초대 버튼 대비4.5 이상.
- 탭 클릭/방향키/Home, 설정 키보드 조작, 숨겨진 탭의 튜토리얼 대상 노출 통과.
- 주사위·룰렛 실제 채팅 전달, 주문 시작 후 입력, 손님 새로고침 권한 유지 통과.
- 주사위 호스트가 손님을 준비 영역으로 드래그하는 실제 동작 통과.
- 경마 전체화면 복귀/데구리 모바일 의사 전체화면 복귀 통과. 네이티브 PiP는 headless 환경에서 검증하지 않았다.
- JS 문법 및 git diff --check 통과.

## 한계와 기존 검사
- 모바일 경마·데구리는 게임 장면과 선택 메뉴를 먼저 보여주므로 준비/시작까지 스크롤이 필요하다. 데구리 캔버스는 결승선 장면을 보존하도록 기존 비율을 유지했다.
- 전체 색상 검사는 수정하지 않은 css/home.css, js/deguri-render.js의 기존30개 리터럴로 실패한다. 새 CSS/JS에는 색 리터럴을 추가하지 않았다.
- 병렬 로컬 QA 중 기존 열린 방 목록 조회가 간헐적으로 시간 초과했다. 초대 링크 경로로 진행한 주사위 입장/채팅/드래그/완주/복귀 검증은 통과했다.
- 광고 네트워크는 브라우저 QA에서 차단했다. 기존 광고 슬롯은 유지했다.

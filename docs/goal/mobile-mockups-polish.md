# 모바일 게임 목업 다듬기

2026-10-12 사용자 요청: Interface In Game을 참고해 현재 모바일 목업을 더 예쁘게 다듬고, 테마를 통일해 테스트 서버에서 볼 수 있게 한다.

## 범위

- 지원 게임 주사위·룰렛·경마·데구리의 준비/진행/결과와 공통 주문·채팅·메뉴, 목업 목록.
- 기존 `mockups/` 시안만 수정. 실제 게임·공유 런타임·서버·테마 원본은 변경하지 않는다.
- 기존 6개 스킨과 색 토큰, 동작과 단계 수를 유지한다.
- 데구리는 좌우 꽉 찬 9:16 세로 게임판, 아래 스크롤, 브라우저 터치 확대를 유지한다.

## 디자인 방향

- [Brawl Stars 로비](https://interfaceingame.com/screenshots/brawl-stars-lobby/)의 캐릭터 중심 배치와 가까운 상태 표시를 참고한다. 이미지나 팔레트는 복제하지 않는다.
- 게임판/캐릭터를 시선 중심으로 삼고, 선택 상태와 결과 순위를 선명하게 한다.
- 헤더·시작 버튼·하단 메뉴·간격·글자 크기를 공통 규칙으로 통일한다.
- 장식 때문에 읽을 글이나 조작 단계를 추가하지 않는다.

## 완료 기준

- 320/375px, 라이트/다크에서 주요 화면 가로 넘침·잘림·누락 이미지·JS 오류가 없다.
- 6개 스킨을 바꿀 수 있고 화면 이동에도 선택한 스킨이 유지된다.
- 준비→진행→결과, 주문/채팅/메뉴 왕복이 동작한다.
- 색 검사와 JS 문법 검사 통과. 첫 화면 정보량은 측정하되 홈 전용 60자/6개 기준을 인게임 합격 기준으로 쓰지 않는다.
- `feature/marble-run` 푸시 후 테스트 배포 성공, 공개 목업 주소 확인.

## 구현 및 로컬 검증

- 공통 헤더 72px, 주요 버튼 52px, 하단 탭 48px와 동일한 테마 표면을 적용했다.
- 주사위 점 그림·룰렛 안 캐릭터·선택 체크·당첨 순위표를 다듬었다. 경마 캐릭터와 내 상태를 확대하고 주문/채팅/메뉴 간격을 맞췄다.
- 16개 화면 × 320/375px × 라이트/다크 = 64조합: 가로 넘침·깨진 이미지·하단 버튼 화면 이탈 0건. 데구리 준비/진행 보드는 화면 전체 너비 유지.
- 메뉴에서 6스킨 선택 동기화, 헤더/푸터 표면 일치 및 채팅/주문 이동 유지 확인.
- 경마 탈것/등수 선택 후 진행→결과 쿼리 유지, 주사위 준비→굴리기→결과, 목업 채팅 입력 확인.
- `measure.js` 준비 화면 글자/조작: 경마60/15, 주사위88/11, 룰렛76/8, 데구리72/14. 검토용 목록104/16. 홈 전용 기준의 자동 ‘미달’ 표시는 인게임 품질 판정에 사용하지 않는다.
- JS 문법·색 리터럴 검사·diff 공백 검사 통과. 실제 게임 코드 변경 없음.

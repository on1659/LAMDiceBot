# 기능을 유지한 완전히 다른 홈 목업 15~17

2026-10-05 사용자 피드백: 12~14는 메뉴 위치만 달라 요청과 다르다. 14처럼 모든 기능은 있어야 한다. 기능을 페이지로 쪼개는 비교가 아니라 화면 구성과 조작 방식이 확실히 다른, 더 편한 목업을 원한다.

## 완료 기준

- 14의 기능엔진을 보존한 독립 HTML 3종. 운영 소스는 수정하지 않는다.
- 서버 먼저 선택, 작은 게임 만들기 → 게임 선택 유지.
- 각 안마다 방·랭킹·기록·멤버·업데이트가 한 로비에 함께 드러난다. 기능별 별도 페이지로 이동하지 않는다. 상세 내용은 같은 화면의 확장 영역/패널 또는 팝업으로 다룬다.
- 계정·서버 관리·6스킨·소리·주문·채팅·초대·게임 설정 등 기존 기능 접근을 유지한다.
- 15: 여백을 줄인 모임 작업대. 서버 레일과 로비 + 옆 정보 패널.
- 16: 따뜻한 모임 보드. 편집된 보드/타일에 열린 방·랭킹·모임 소식을 동시에 배치.
- 17: 가벼운 접이식 리스트. 카드와 탭의 반복 없이 필요한 내용을 바로 펼치는 밀도 높은 화면.
- 색만 바꾸거나 메뉴 위치만 옮긴 안을 만들지 않는다. 375×812 / 1200×900, 라이트·다크와 생성/랭킹/주요 기능을 확인한다.
- 이전 60자/6조작 제한은 이번에 모든 핵심 기능을 한 로비에 노출하는 요구보다 우선하지 않는다. 설명을 줄이고 실제 데이터를 간결히 배치한다.

## 완료 결과

- 15 `mockups/15.html`: PC 서버 레일/중앙 방/우측 요약 3열, 모바일은 방 아래 순위·멤버를 나란히 배치. 서버 변경은 로비를 유지한 채 선택 팝업을 연다.
- 16 `mockups/16.html`: 따뜻한 보드. 열린 방의 큰 영역, 순위·멤버 타일, 짧은 기록·업데이트를 같은 화면에 배치한다.
- 17 `mockups/17.html`: 가는 선과 목록 중심. 랭킹·지난 기록·멤버·업데이트를 독립적으로 펼친다. PC는 방/정보 2열, 모바일은 한 열.
- 비교 허브 `/main`은 새 3안의 실제 화면 미리보기를 나란히 제공한다. 1~14는 '이전 목업' 안에 보존했다.
- 세 안 모두 14의 공통 기능 엔진을 유지한다. 상세한 운영 기능을 목업 안에서 재구현한 것은 아니며, 예시 상태와 기존 실제 게임/문서 링크의 범위는 `home-feature-variants-report.md`와 같다. 주요 로비 기능은 페이지 이동 없이 요약·인라인 확장·상세 팝업으로 접근한다.

## 검증

- 375×812 / 1200×900, 3안 총 6조합: 생성/합류/4게임 선택/랭킹/시즌/달력/메뉴/계정 메뉴/서버 검색·신청·코드/초대 복귀/채팅/주문/방 설정/준비/관리자 기능 클릭 통과. JS 오류 0.
- 라이트·다크 화면 육안 검토, 가로 넘침 없음. 6스킨은 실제 계산된 배경색이 서로 다름을 확인했다.
- 서버→자유 전환 시 서버의 개인 순위·멤버를 보여주지 않는다. 새 시즌 이후 로비 순위 요약도 빈 시즌 상태로 갱신한다.
- 17의 네 접이식 영역을 동시에 펼칠 수 있고 페이지 이동이 없다.
- 허브 375/1200, 미리보기 3개 로드와 가로 넘침 확인. 화면 미리보기는 `mockups/assets/preview-{15,16,17}.png`.

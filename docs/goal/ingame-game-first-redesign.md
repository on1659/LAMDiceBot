# 인게임 화면 재설계

2026-10-07 사용자가 인게임도 다시 디자인해 달라고 요청했다. 첫 적용은 종이색과 테두리를 바꿨지만 긴 세로 패널 구조가 남았다.

## 목표
- 주사위·룰렛·경마·데구리 실제 게임 화면을 가장 먼저 표시한다.
- PC는 게임판 + 오른쪽 참가/준비/시작 패널, 모바일은 게임판 다음 조작 패널로 배치한다.
- 방 헤더는 게임명·방명·친구 초대·도구로 압축하고 채팅/기록/주문은 기존 DOM을 유지한 탭으로 통합한다.
- 게임 결과, 초대, 소켓 계약, 호스트 권한, 전체화면 동작을 유지한다.
- 라이트/다크, 375px/1280px, 2인 플레이를 검증하고 테스트 서버에 반영한다.

## 구현/검증
- [x] 네 게임 DOM/게임별 CSS 재구성
- [x] 공통 레이아웃/탭/초대 접근성 구현
- [x] 브라우저 화면 및 2인 플레이 검증
- [x] 테스트 서버 배포 확인

데구리 캔버스 비율은 결승선과 전체 장면이 보이도록 유지한다. 서버/결과 로직은 변경하지 않는다.
